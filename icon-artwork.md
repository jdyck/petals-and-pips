# Pips & Petals icons

The app and Home Screen icons use watercolor roses and a white five-pip die to match the game. The browser favicon uses a simplified vector version for legibility at 16–48 pixels.

Assets:

- `public/icons/pips-and-petals-1024.png`: master artwork.
- `public/icons/pips-and-petals-512.png`: 512×512 app icon.
- `public/icons/pips-and-petals-192.png`: 192×192 install icon.
- `app/apple-icon.png`: 180×180 Home Screen icon.
- `app/icon.svg`: scalable browser favicon.
- `app/favicon.ico`: 16, 32, and 48 pixel favicon variants.

The PNG artwork was created with the built-in ImageGen tool using `public/bgs/01-pink-wild-rose.png` as a style reference, then resized with Sharp. The app images are opaque full squares so each platform can apply its own icon shape.

## Generation prompt

Use case: logo-brand.
Asset type: finished square app icon artwork for Pips & Petals, a refined floral five-dice game.
Input image 1 is a STYLE AND PALETTE REFERENCE ONLY: the game's actual watercolor pink wild rose background. Create a NEW square icon composition, not a screenshot or device mockup.
Primary request: one large beautiful ivory-white rounded die, nearly face-on with only a very slight 3D edge and a modest 8-degree tilt, showing exactly FIVE large dark slate-navy circular recessed pips, four corners plus center. The die occupies about 60 percent of the canvas width and is the unmistakable focal point. Place the die centered with generous clearance from all image edges.
Surround the die with a restrained diagonal arrangement of soft hand-painted blush-pink wild rose blossoms and sage leaves, concentrated in the lower-left and upper-right corners, like the reference. A few larger simple flowers, not an ornate wreath. Florals remain secondary and don't obscure any pips. Subtle paper texture and a very pale warm blush watercolor wash over the entire backdrop; airy, calm, elegant. Soft short shadow beneath the die, realistic white rounded face like the game's dice. Dark navy #25344d pips, muted rose #92536b accents. The die and pips must remain clear at tiny app-icon sizes.
Composition: square 1024x1024, artwork fills the entire square edge to edge, opaque background. NO outer rounded-corner mask, border, white margin, icon container, text, letters, title, monogram, watermark, UI, extra dice, or mockup. iOS will supply its own corner mask.
